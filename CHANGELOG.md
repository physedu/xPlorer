# Changelog

## 1.0.0-beta.1 — first public beta candidate (unreleased)

- Register an abstract xAct theory once and reuse it across independent geometric backgrounds in one Mathematica kernel.
- Transport equations and compute tensor components with native xTensor, xCoba and xPert, including scalar, vector and tensor profiles, secondary charts, affine connections and metric perturbations.
- Inspect and reconstruct managed background data and customize mathematical notation independently of symbolic identity.
- Provide the research Workflow and the advanced API Examples notebooks, direct source loading and a paclet build workflow.
- Start public semantic version numbering at 1.0.0-beta.1. Simplify the startup banner and include the project URL.
- Separate executable regression tests from historical internal development reports.

See [VALIDATION.md](VALIDATION.md) for actual execution evidence and remaining release checks. Internal versions are historical development identifiers, not public version increments.
